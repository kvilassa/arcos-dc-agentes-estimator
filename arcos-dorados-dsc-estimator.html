Cómo usar:
1Completá las celdas editables de cada fila: caso de uso, tipo, ambiente, volumen y frecuencia.
2Los créditos se calculan solos. Volumen = filas que procesa cada ejecución.
3Para streaming o consumos puntuales, elegí "Mensual / Puntual" y cargá el total mensual.
4Revisá el total y el desglose a la derecha. Cargá tu allowance para ver el runway.
⚠️ Nota: consumo especial de Data Graph
  • Batch Data Transform: se genera/actualiza el Data Graph → suma todos los registros de input de la Data Transform para obtener los registros procesados por ejecución. Tarifa: 400 créditos por 1M registros.
  • Data Queries: cada consulta al Data Graph consume Data Queries. Tarifa: 2 créditos por 1M registros. Para estimar el volumen: si la consulta filtra sólo por PK del objeto principal → asumir 600.000 registros por consulta. Si tiene filtros adicionales → asumir la totalidad de registros del DMO principal presentes en el DG.

Tarifas — Salesforce Data Cloud

Rate Card · Last Updated August 2025
Fuente: Salesforce Customer Data Cloud Platform Services — Rate Card August 2025. Multiplicadores en Data Services Credits (DSC).
Cómo usar:
1Completá cada agente: nombre, tipo de complejidad, ambiente, interacciones mensuales y acciones por interacción.
2Los Flex Credits se calculan solos. Fórmula: Vol. mensual × acciones × FC por acción.
3Si el agente consulta Data Cloud, activá el toggle — los DSC de queries se calculan aparte en la otra calculadora.
4Aplicá un buffer de seguridad según la madurez del caso de uso.
⚡ Tarifas Flex Credits (FC) — referencia rápida
  • Acción estándar: 20 FC / acción en producción · 16 FC en sandbox.
  • Acción de voz: 30 FC / acción en producción · 24 FC en sandbox. 50% más cara que estándar.
  • Prompt estándar (LLM): 4 FC / 2.000 tokens · Prompt avanzado: 16 FC / 2.000 tokens.
  • Help Agent resolution: 400 FC / resolución exitosa.
  • Turnos sin acción (saludos, chit-chat) no consumen crédito.
  • Tip: slot fill ahorra créditos — pedir varios datos en 1 turno (20 FC) vs. 3 turnos separados (60 FC).
  • Atención: Flows y Apex corriendo dentro del agente NO reducen el consumo — el billing es por la acción disparada. Atlas Reasoning es el "consumidor #1" de créditos en agentes sobre-diseñados.

Glosario — Usage Types de Data Services Credits

Qué significa cada tipo de consumo y cuándo se incurre en él

Cada fila de la calculadora corresponde a un Usage Type — una operación facturada en Data Services Credits (DSC). La tabla a continuación explica qué hace cada tipo, en qué escenario se activa y cuál es la unidad de medida.

Connect, Harmonize & Unify

Ingesta, transformación y preparación de datos en Data Cloud
Usage Type Descripción Unidad de medida
Internal Data Pipeline Mueve datos desde nubes Salesforce internas (Sales Cloud, Service Cloud, Marketing Cloud, etc.) hacia Data Cloud a través de los conectores nativos de Salesforce. Tarifa cero: Salesforce no cobra DSC por esta ingestión — es el mecanismo preferido para traer datos CRM propios. 1M filas procesadas
External Data Pipeline (Batch) Ingesta en lote de fuentes externas a Salesforce: bases de datos on-premise, data lakes, archivos CSV/JSON subidos vía API, buckets S3, etc. Los datos son procesados, mapeados a DMOs y escritos en el almacén de Data Cloud. Se factura por cada millón de filas procesadas. 1M filas procesadas
External Data Pipeline (Streaming) Ingesta continua en tiempo real de fuentes externas: eventos de apps móviles, clics web, streams de Kafka, webhooks. Los datos llegan en flujo constante y se procesan casi en tiempo real. Tarifa más alta que batch debido al procesamiento continuo. 1M filas procesadas
Data Transforms (Batch) Transformaciones SQL programadas que consolidan, enriquecen o calculan métricas sobre DMOs existentes en Data Cloud (ej.: construir un DMO de "clientes activos 90 días" desde múltiples fuentes). Se ejecutan en ventanas horarias o diarias. También se activa cuando se genera o actualiza un Data Graph. 1M filas procesadas
Data Transforms (Streaming) Versión en tiempo real de las Data Transforms: las reglas SQL se aplican sobre el stream de datos a medida que ingresan, sin esperar una ventana batch. Útil para enriquecimientos inmediatos como calcular el score de un cliente en el instante de la transacción. 1M filas procesadas
Unstructured Data Processed Procesamiento de contenido no estructurado: documentos PDF, transcripciones de llamadas, emails, imágenes. Data Cloud extrae texto, vectoriza y almacena embeddings para búsqueda semántica y casos de IA generativa. Se factura por megabyte procesado — la unidad más pequeña de la Rate Card. MB procesado
Intelligent Processing Procesamiento de datos no estructurados con modelos de IA integrados: OCR en documentos, extracción de entidades (NER), clasificación automática de tickets, análisis de sentimiento en texto libre. Se activa cuando Data Cloud aplica un modelo de ML en la etapa de ingesta o transformación del contenido. Tarifa más alta que Unstructured Data por el costo computacional de la inferencia. MB procesado
Data Federation or Sharing Rows Accessed Acceso a datos federados que residen en sistemas externos sin moverlos a Data Cloud: Snowflake, BigQuery, Redshift vía Zero-Copy o Data Federation. Cada fila leída desde el sistema externo para enriquecer un perfil o segmento cuenta. El dato nunca se copia — solo se consulta en origen. 1M filas accedidas
Data Share Rows Shared (Data Out) Compartición de datos procesados en Data Cloud hacia otros sistemas externos: exportar segmentos a Snowflake, publicar perfiles unificados en un data lake propio del cliente, o habilitar acceso de lectura a terceros. Se factura por las filas enviadas "hacia afuera" del ecosistema Data Cloud. 1M filas compartidas
Private Connect Data Processed Transferencia de datos a través de Salesforce Private Connect — conexión privada y cifrada entre Data Cloud y sistemas externos del cliente sin pasar por la internet pública (equivalente a AWS PrivateLink). Se factura por gigabyte transferido. Recomendado para industrias reguladas (banca, salud). GB procesado
Profile Unification El motor de Identity Resolution de Data Cloud compara, deduplica y consolida registros de distintas fuentes para construir un Unified Individual Profile. Cada fila procesada en la ejecución del Identity Resolution (IR) cuenta. Es el usage type más costoso de la categoría — un IR sobre millones de registros puede consumir DSC de forma significativa. 1M filas procesadas

E2E Real-Time Processing

Eventos y acciones en tiempo real sub-segundo
Usage Type Descripción Unidad de medida
Sub-second Real-Time Events Procesamiento de eventos con latencia sub-segundo: un evento (clic, apertura de email, transacción) llega, enriquece el perfil unificado en tiempo real y dispara una acción (mostrar oferta, enviar notificación push, actualizar score) — todo en menos de 1 segundo. Es el mecanismo que alimenta la "próxima mejor oferta" en el momento exacto de la interacción. Es la tarifa más alta de toda la Rate Card por la infraestructura dedicada que requiere. 1M eventos / API / acciones

Analyze & Predict

Insights calculados, predicciones e inferencias de modelos de IA
Usage Type Descripción Unidad de medida
Calculated Insights (Batch) Métricas y KPIs calculados mediante SQL sobre los perfiles unificados, ejecutados en ventanas programadas (horarias, diarias, semanales). Ejemplos: "total gastado en 90 días", "frecuencia de visitas en el último mes", "ticket promedio". Los resultados se escriben como atributos en el Unified Profile y quedan disponibles para segmentación. 1M filas procesadas
Calculated Insights (Streaming) Versión en tiempo real de los Calculated Insights: el cálculo ocurre en el instante en que llega un evento, sin esperar la ventana batch. Ideal para actualizar un "score de propensión" o "saldo acumulado de puntos" en tiempo real durante la interacción del cliente. 1M filas procesadas
Inferences Ejecución de modelos de Machine Learning propios del cliente (importados vía Amazon SageMaker, Google Vertex AI, etc.) o modelos nativos de Einstein Prediction Builder sobre los perfiles de Data Cloud. Cada predicción generada (ej.: "probabilidad de churn", "lifetime value estimado", "próxima categoría a comprar") cuenta como una inferencia. Distinto de los Flex Credits de Agentforce — estos son modelos de ML clásico. 1M inferencias

Act

Consultas y acciones de activación basadas en datos del Data Graph
Usage Type Descripción Unidad de medida
Data Queries Consultas a un Data Graph de Data Cloud — el grafo de conocimiento que conecta perfiles, transacciones y eventos. Se activa principalmente cuando Agentforce consulta el perfil de un cliente para personalizar una respuesta. Tarifa muy baja (2 DSC/1M filas) pero puede acumularse con alto volumen de consultas. Regla de estimación: si la query filtra por PK → 600K registros; si tiene filtros adicionales → total del DMO principal. 1M filas procesadas
Streaming Actions (including Lookups) Acciones disparadas en tiempo real desde Data Cloud hacia sistemas externos: enviar un evento a Marketing Cloud Engagement, actualizar un registro en Sales Cloud, llamar a una API externa, o hacer un "lookup" enriqueciendo datos en tránsito. Cada acción o lookup enviado como parte del flujo streaming cuenta. Incluye las integraciones bidireccionales de Agentforce con Data Cloud. 1M filas procesadas

Segmentation & Activation

Construcción de segmentos y envío de audiencias a canales
Usage Type Descripción Unidad de medida
Segment Rows Processed Evaluación de criterios de segmentación sobre los perfiles unificados para construir o actualizar un segmento de audiencia. Cada vez que Data Cloud recorre los perfiles para calcular quién entra o sale del segmento, se cobran las filas examinadas. Los segmentos con refresh frecuente (horario o diario) generan mayor consumo. 1M filas procesadas
Batch Activation Envío programado de un segmento de audiencia a un canal de marketing: Marketing Cloud Engagement, Meta Ads, Google Ads, Amazon Ads, Salesforce CDP partners. Data Cloud exporta las filas del segmento al destino en una ventana batch. Tarifa la más baja de Segmentation & Activation porque el costo mayor ya fue en construir el segmento. 1M filas procesadas
Activate DMO - Streaming Activación en tiempo real de cambios en un Data Model Object (DMO) hacia sistemas externos. Cuando un perfil cambia de segmento o un atributo se actualiza, el cambio se propaga inmediatamente al canal destino sin esperar un ciclo batch. Útil para personalización en tiempo real en apps, sitios web o call centers. Tarifa alta por la infraestructura de streaming dedicada. 1M filas procesadas

Compute

Extensiones de código y lógica personalizada
Usage Type Descripción Unidad de medida
Code Extension Ejecución de código personalizado (Python, Node.js) dentro del entorno de Data Cloud para lógica de negocio que no puede expresarse en SQL: algoritmos de scoring propietarios, integraciones complejas, validaciones customizadas. Se factura por Compute Unit — una unidad basada en CPU + tiempo de ejecución. Usar con moderación; preferir Data Transforms SQL cuando sea posible. Compute Unit
